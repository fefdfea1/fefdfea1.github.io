Next Js 쇼핑몰 제작 프로젝트 서버개발

이번 포스팅에서는 이전에 생성한 mongodb와 우리가 만든 next js 프로젝트를 연결하여 데이터를 불러오는 작업을 진행해보도록 하겠다.

api 폴더 생성

이전 포스팅에 잠시 next js에서 서버 개발 방법을 설명하기 위해 App 라우터와 page 라우터의 방식을 각각 알아보았다. 이번에도 그때 설명한 App라우터 방식으로 진행하니 해당 포스터를 보고 와도 좋고 그냥 같이 따라 만들어 보아도 좋다

위의 이미지는 우리가 만든 쇼핑몰의 폴더구조이다 여기서 서버 개발을 위해 app 폴더안에 api라는 폴더를 하나생성하자 필자는 이미 생성해서 생략하겠다.

api 폴더를 생성하였다면 해당 폴더안에 새로운 폴더를 하나 더 생성하고 route.ts or js 라는 파일을 하나 생성하도록 하자 필자는 아래와 같이 생성하였다.

mongodb를 사용하기 위한 파일을 생성하였다면 해당 파일을 mongodb 연결에 필요한 코드를 입력하도록하자 필자는 app폴더에 utils 폴더를 만들어 거기에 작성하도록 하겠다.

다음과 같이 utils 폴더안에 db 연결 모듈을 생성하기 위한 파일을 하나 만들고 아래의 코드를 복사 붙여넣기 하도록 하자 그후 코드를 확인하면 env를 이용하여 개발환경에서 실행하는 것과 그렇지 않을떄 실행하는 방법이 다른데 next js에서 변경사항이 생기면 코드를 다시 실행하는 특성상 mongodb 연결이 여러개 생길 수 있기 때문에 이처럼 global 객체를 사용한다 그러니 우선 env를 설정하자

import { MongoClient } from 'mongodb';

const url =
  'mongodb+srv://[아이디]:[비밀번호]@cluster0.dggv7bb.mongodb.net/?retryWrites=true&w=majority';
const options: any = { useNewUrlParser: true };
let connectDB: Promise<MongoClient>;

if (process.env.NODE_ENV === 'development') {
  // 개발 중 재실행을 막음
  if (!global._mongo) {
    global._mongo = new MongoClient(url, options).connect();
  }
  connectDB = global._mongo;
} else {
  connectDB = new MongoClient(url, options).connect();
}

export { connectDB };

이렇게 복사 붙여넣기하면 아래와 같은 오류가 생길텐데

이 부분은 최상위 경로에 global.d.ts 파일을 생성하고 global 설정을 하여 해결 할 수 있다. 아래와 같이 파일을 우선 생성하도록 하자

해당 파일안에 아래와 같은 코드를 복사 붙여넣기를 하도록 하자

  import type { MongoClient } from "mongodb";

declare global {
  namespace globalThis {
    var _mongo: Promise<MongoClient>;
  }
}

여기까지 하면 오류가 사라졌을 것이다. 그럼 다음으로 env 설정을 해보도록 하자 env는 최상위 경로 .env로 파일을 하나 생성하여 진행 하도록하겠다.

다음과 같이 최상위 경로에 .env 파일을 생성해주고 env에 아래와 같이 입력한뒤 개발환경을 재실행한다.

NODE_ENV = development

이제 mongodb와 연결을 해보자 이전에 접속했었던 mongodb 사이트를 다시 접속하여 database에 접속하면 아래와 같이 자신이 만든 cluster 정보가 나올 것이다.

이 화면에서 connect를 눌러 오른쪽에

Add connection string into your application code

이라는 글자 밑에 주소를 복사하고 아까 코드에서 만들었던 database.ts 파일에 url 칸에 이를 붙여넣기 해준다. 그리고 <paassword> 라고 되어있는 부분을 자신의 비밀번호를 입력해주면 된다. 여기까지 되었다면 본격적으로 db의 데이터를 호출할 수 있는 환경이 세팅되었다.

그럼 본격적으로 해당 데이터를 호출해보도록 하자 (해당 데이터는 그냥 테스트를 위해 임시로 만든 데이터이다)

이곳 string 부분에 데이터를 불러와 넣어보도록 하겠다. 데이터 호출은 page 컴포넌트에서 진행하도록 하겠다.
